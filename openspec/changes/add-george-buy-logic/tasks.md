# George买入逻辑实现任务列表

## 任务1：初始化状态跟踪存储
- **描述**：在 `initialize` 函数中初始化全局状态存储变量
- **验证**：确保 `g.stock_previous_status` 被正确初始化为空字典
- **依赖**：无

## 任务2：实现状态跟踪逻辑
- **描述**：在 `interval_handle` 函数中添加状态跟踪机制
  - 获取当前股票状态
  - 从存储中读取上一次状态
  - 更新存储中的状态
- **验证**：确保每只股票的状态被正确记录和更新
- **依赖**：任务1

## 任务3：实现买入条件判断
- **描述**：在 `interval_handle` 函数中添加买入条件判断逻辑
  - 检查上一次状态是否为 0, -1, -2
  - 检查当前状态是否为 2
  - 满足条件时记录 info 级别日志
  - 不满足条件时记录 debug 级别日志
- **验证**：测试各种状态组合，确保日志输出正确
- **依赖**：任务2

## 任务4：实现状态分类存储
- **描述**：在 `initialize` 函数中初始化状态分类存储
  - 初始化 `g.limit1` 为空集合（存储状态为1的股票）
  - 初始化 `g.limit2` 为空集合（存储状态为2的股票）
  - 在处理过程中更新这两个集合
- **验证**：确保股票被正确分类存储
- **依赖**：任务1

## 任务5：集成测试验证
- **描述**：运行策略并验证所有功能正常工作
  - 验证状态跟踪机制
  - 验证买入条件判断
  - 验证日志输出
  - 验证状态分类存储
- **验证**：检查日志输出和状态存储是否符合预期
- **依赖**：任务2, 任务3, 任务4
