# George买入逻辑设计

## 设计思路

### 状态跟踪机制
1. 使用全局变量 `g.stock_previous_status` 存储每只股票的上一次状态
2. 在每次处理时更新股票的当前状态
3. 实现状态变化检测逻辑

### 买入条件
1. 上一次状态为 0, -1, -2 中的任意一种
2. 当前状态为 2
3. 满足以上两个条件时触发买入操作

### 状态存储优化
1. 使用字典结构存储股票状态，便于快速查找和更新
2. 为未记录的股票设置默认状态值为 0

## 技术实现

### 数据结构
```python
# 全局状态存储
g.stock_previous_status = {}  # {stock_code: status}
```

### 状态流转逻辑
```
previous_status ∈ {0, -1, -2} AND current_status == 2 => 触发买入
otherwise => 记录调试日志
```

### 日志记录
1. 买入条件满足时使用 `log.info` 记录详细信息
2. 未满足条件时使用 `log.debug` 记录调试信息

## 集成考虑

### 与现有代码的兼容性
1. 保持现有的 `check_limit` 函数调用逻辑
2. 不改变现有的错误处理机制
3. 继承现有的日志级别控制策略

### 性能影响
1. 状态存储操作时间复杂度为 O(1)
2. 状态比较操作时间复杂度为 O(1)
3. 对整体策略性能影响极小
